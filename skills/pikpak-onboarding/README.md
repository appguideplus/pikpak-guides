# PikPak onboarding by AppGuide+

An independent onboarding skill for an AI assistant: choose an existing account or new registration, complete account verification, then save and download one file the user is entitled to use.

## Install or read

1. Read [SKILL.md](SKILL.md) before installing. It is plain guidance, with no executable installer or bundled account credentials.
2. Download that file and place it in a `pikpak-onboarding` folder in your AI tool’s supported project skill directory. Keep the filename `SKILL.md`. Follow your tool’s current skill installation documentation; this repository does not install anything globally.
3. Ask your assistant to use the skill for the intended PikPak task. This skill replies in your language and complements the [official PikPak CLI operation skill](https://mypikpak.com/en-US/cli). It does not replace the CLI, sign in automatically, or grant file access.

Example: “Use pikpak-onboarding to help me get started. Let me choose whether to use a referral, then save one file I select and download it to my device.”
