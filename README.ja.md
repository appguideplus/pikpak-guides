## 最初に知っておきたい2つの違い

**クラウドに保存する** — リンク先のファイルをPikPakのアカウントに取り込む操作です。完了しても、スマートフォンやパソコンにコピーが保存されるわけではありません。

**端末にダウンロードする** — PikPakにあるファイルをスマートフォンやパソコンに保存する操作です。端末の空き容量と保存先を確認してください。

## どの端末から始める？

- **パソコン:** Web版なら、専用アプリをインストールせずにファイルを操作できます。
- **Android:** PikPakアプリでファイルを確認・再生できます。メニューの位置はバージョンによって異なる場合があります。
- **iPhone・iPad:** iOSアプリ内ではダウンロードリンクを追加できません。Web版でリンクを保存し、同じアカウントでアプリを開いてください。

Web版ではフォルダ全体をダウンロードできません。中のファイルを個別に保存するか、PikPakのデスクトップアプリを使ってください。

### 端末のファイルをアップロードするには

上部の「Upload」から「Upload Files」を選び、ファイルを指定します。フォルダは「Upload Folder」を使います。完了後、ファイル一覧で確認してください。

Web版ではファイルを右クリックして操作メニューを開けます。「Move」は移動、「Rename」は名前変更、「Download to Device」は端末へのダウンロードです。

## 1. PikPakにファイルを保存する

自分で作ったファイルや、利用する権利のある資料で試しましょう。

1. PikPak Web版にログインします。アプリでも見る場合は、同じアカウントを使います。
2. マグネットリンクやトレントファイルは「Cloud Download」から追加します。リンクを貼り付けるか、トレントファイルを選びます。
3. 「Create Now」でタスクを開始して完了を確認し、ファイル一覧から保存したファイルを探します。

クラウドへの保存が終わるまでは、再生やダウンロードができない場合があります。

![Cloud Download：リンクやトレントファイルの追加](https://appguideplus.com/assets/pikpak-cloud-download.png?utm_source=github)

[リンク保存の公式ヘルプ](https://mypikpak.com/en-US/help-center/beginner_tutorial/save_content/margnet_link)

## 2. フォルダで整理する

ファイルが増える前に、わかりやすいフォルダ名を決めておきましょう。

1. ファイル一覧の上にある「Create Folder」を開き、「旅行動画」などの名前を付けます。
2. 整理するファイルを選び、ファイルメニューの移動操作を開きます。
3. 移動先のフォルダを選んで操作を完了し、そのフォルダにファイルがあるか確認します。
4. ファイル名は名前変更の操作から変えられます。拡張子はそのまま残しましょう。

フォルダへの移動と、ゴミ箱への移動は別の操作です。選択した操作と移動先を確認してください。

![フォルダ名を入力して「Create」を選択](https://appguideplus.com/assets/pikpak-create-folder.png?utm_source=github)

## 3. 保存した動画を再生する

クラウドへの保存が完了した動画を開きます。

1. ファイル一覧またはフォルダから動画を開きます。
2. 映像と音声を確認します。必要に応じて、プレーヤーに表示される画質・字幕の設定を使います。
3. Web版でエラーになる場合は、同じアカウントのPikPakアプリで試してください。Androidでは対応する動画のメニューから、別のプレーヤーで再生することもできます。

対応状況は動画形式、音声コーデック、ブラウザーによって異なります。どの端末でも同じように再生できるとは限りません。

[動画再生の公式ヘルプ](https://mypikpak.com/en-US/help-center/play_and_download/playback)

## 4. スマートフォン・パソコンに保存する

オフラインで使うファイルは、端末にダウンロードしておきましょう。

1. Web版ではファイルを右クリックして「Download to Device」を選びます。アプリではファイルのダウンロード操作を開きます。
2. 開始後、完了まで進行状況を確認します。Web版ではブラウザーのダウンロード一覧も確認してください。
3. 完了したファイルの保存先を開きます。ブラウザーやアプリで設定したダウンロードフォルダを確認しましょう。
4. 保存したファイルを開き、正常に使えるか確かめます。

アプリ内のオフライン保存と、「写真」「ファイル」への書き出しは異なる場合があります。別のアプリで使う場合は保存先や書き出し操作を確認してください。

![ファイルメニュー：再生・ダウンロード・移動](https://appguideplus.com/assets/pikpak-file-menu.png?utm_source=github)

Web版ではフォルダ全体をダウンロードできません。中のファイルを個別に保存するか、PikPakのデスクトップアプリを使ってください。

[フォルダのダウンロードに関する公式ヘルプ](https://mypikpak.com/en-US/help-center/play_and_download/failure/web)

メニュー名は表示言語やアプリのバージョンによって異なる場合があります。

## うまくいかないとき

### アプリにファイルが見つからない

Web版とアプリのアカウントが同じか、保存タスクが完了しているかを確認し、一覧を更新してください。

### リンクを保存できない

リンクと配信元が利用可能か、保存容量や転送量の上限に達していないかを確認してください。配信元の状態で保存が遅れたり失敗したりする場合もあります。

### 保存済みなのにダウンロードが遅い

クラウドへの保存と端末への転送は別です。通信状態、残りの転送量、アカウントの利用条件を確認してください。

### ダウンロードしたファイルが見つからない

ブラウザーの履歴やPikPakのダウンロード一覧から保存先を確認してください。スマートフォンの写真アプリに自動表示されるとは限りません。
