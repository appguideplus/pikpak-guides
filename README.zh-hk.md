## 先分清兩種儲存方式

**儲存到雲端** — 把連結中的檔案存入 PikPak 帳戶。任務完成後，檔案不會自動出現在手機或電腦上。

**下載到裝置** — 把 PikPak 中的檔案下載到手機或電腦。請先確認裝置的剩餘空間及下載位置。

## 用哪個裝置開始？

- **電腦:** 直接開啟網頁版便可處理檔案，毋須另外安裝應用程式。
- **Android:** 在 PikPak 應用程式內查看及播放檔案。不同版本的選單位置可能有所不同。
- **iPhone、iPad:** iOS 應用程式內不能新增下載連結。請先在網頁版儲存連結，再用同一帳戶在應用程式內開啟檔案。

網頁版不能下載整個資料夾。請逐一下載當中的檔案，或使用 PikPak 桌面應用程式。

## 遇到問題時先檢查

### 應用程式內找不到檔案

確認應用程式與網頁版登入的是同一帳戶，重新整理檔案清單，並檢查儲存任務是否完成。

### 連結儲存失敗

確認連結有效、來源檔案仍可取得，帳戶的儲存空間和傳輸配額尚有餘額。來源狀態亦可能令任務延遲或失敗。

### 雲端已儲存，但下載仍然很慢

雲端儲存和下載到裝置是兩次不同的傳輸。請檢查網絡、剩餘傳輸配額及帳戶目前的使用條件。

### 找不到已下載檔案

從瀏覽器下載記錄或 PikPak 下載清單開啟儲存位置。手機下載的檔案不一定自動出現在相片應用程式。
