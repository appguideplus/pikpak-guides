| 하려는 작업 | 웹 메뉴 |
| --- | --- |
| 파일을 PikPak에 저장하기 | Cloud Download → Create Now |
| 폴더로 정리하기 | Create Folder / Move / Rename |
| 저장한 영상 재생하기 | Open |
| 휴대폰·컴퓨터로 다운로드하기 | Download to Device |

## 먼저 알아두면 좋은 두 가지

**클라우드에 저장하기** — 링크의 파일을 PikPak 계정에 가져오는 단계입니다. 저장이 끝나도 휴대폰이나 컴퓨터에 파일이 생기는 것은 아닙니다.

**기기로 다운로드하기** — PikPak에 저장된 파일을 휴대폰이나 컴퓨터로 내려받는 단계입니다. 기기의 저장 공간과 다운로드 위치를 확인하세요.

## 어디서 시작하면 되나요?

- **컴퓨터:** 웹 드라이브에서 시작하면 별도 앱 설치 없이 파일과 메뉴를 확인할 수 있습니다.
- **Android:** PikPak 앱에서 파일을 확인하고 재생할 수 있습니다. 메뉴 위치는 앱 버전에 따라 다를 수 있습니다.
- **iPhone·iPad:** 앱 안에서는 다운로드 링크를 추가할 수 없습니다. 웹 드라이브에서 링크를 저장한 뒤, 같은 계정으로 앱에 로그인해 파일을 여세요.

웹에서 폴더 전체를 다운로드할 수는 없습니다. 안의 파일을 개별로 내려받거나 PikPak 데스크톱 앱을 사용하세요.

## 막히는 부분이 있나요?

### 앱에서 파일이 보이지 않아요

웹과 앱의 로그인 계정이 같은지 확인하고 파일 목록을 새로고침하세요. 저장 작업이 완료됐는지도 확인합니다.

### 링크를 넣었는데 저장이 안 돼요

링크가 유효한지, 해당 자료를 받을 수 있는지, 저장 공간이나 전송량 한도에 걸리지 않았는지 확인하세요. 원본 자료의 상태에 따라 저장이 지연되거나 실패할 수 있습니다.

### 저장은 끝났는데 다운로드가 느려요

클라우드 저장 완료와 기기 다운로드 속도는 별개입니다. 네트워크 상태, 남은 전송량, 계정에 적용된 이용 조건을 확인하세요.

### 다운로드한 파일을 찾을 수 없어요

브라우저 다운로드 기록이나 PikPak 앱의 다운로드 목록에서 저장 위치를 확인하세요. 휴대폰의 사진 앱에 자동으로 나타난다고 가정하지 마세요.
