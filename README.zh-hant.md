## 先分清楚兩種儲存方式

**儲存到雲端** — 把連結中的檔案存入 PikPak 帳號。任務完成後，檔案不會自動出現在手機或電腦裡。

**下載到裝置** — 把 PikPak 中的檔案下載到手機或電腦。請先確認裝置的剩餘空間與下載位置。

## 從哪個裝置開始？

- **電腦:** 直接開啟網頁版就能處理檔案，不必另外安裝 App。
- **Android:** 在 PikPak App 中查看及播放檔案。不同版本的選單位置可能不同。
- **iPhone、iPad:** iOS App 內無法新增下載連結。請先在網頁版儲存連結，再用同一個帳號在 App 中開啟檔案。

網頁版無法下載整個資料夾。請逐一下載其中的檔案，或使用 PikPak 桌面版 App。

### 上傳裝置中的檔案

開啟頂部的 Upload，選擇 Upload Files，再選取檔案。上傳資料夾時使用 Upload Folder。完成後在檔案清單中確認結果。

網頁版可以在檔案上按滑鼠右鍵開啟操作選單。Move 是移動，Rename 是重新命名，Download to Device 是下載到裝置。

## 1. 將檔案儲存到 PikPak

先用自己製作或有權使用的檔案試一次。

1. 登入 PikPak 網頁版。若也要在 App 中查看，請使用同一個帳號。
2. 新增磁力連結或種子檔案時，開啟雲端下載（Cloud Download），貼上連結或選取種子檔案。
3. 選擇 Create Now 開始任務並確認完成，再到檔案清單中找到儲存的檔案。

雲端儲存完成前，檔案可能還無法播放或下載。

![雲端下載：新增連結或種子檔案](https://appguideplus.com/assets/pikpak-cloud-download.png)

[官方連結儲存說明](https://mypikpak.com/en-US/help-center/beginner_tutorial/save_content/margnet_link)

## 2. 用資料夾整理

趁檔案還不多時先分類，之後更容易找到。

1. 選擇檔案清單上方的 Create Folder，輸入容易辨識的名稱，例如「旅行影片」。
2. 選取要整理的檔案，開啟檔案選單中的移動功能。
3. 選擇目標資料夾並完成移動，再開啟資料夾確認結果。
4. 需要修改檔名時，使用重新命名功能，保留原本的副檔名。

移到資料夾與移到垃圾桶是不同操作。請確認所選操作及目標位置。

![新增資料夾：輸入名稱後選擇 Create](https://appguideplus.com/assets/pikpak-create-folder.png)

## 3. 播放已儲存的影片

雲端儲存完成後，開啟影片檔案。

1. 從檔案清單或資料夾中開啟影片。
2. 確認畫面與聲音，依需要使用播放器提供的畫質或字幕設定。
3. 網頁版播放失敗時，可用同一帳號在 PikPak App 中嘗試。Android 中支援的影片選單也可以使用其他已安裝的播放器。

播放相容性取決於檔案格式、音訊編碼與瀏覽器。同一個檔案在不同裝置上的表現可能不同。

[官方影片播放說明](https://mypikpak.com/en-US/help-center/play_and_download/playback)

## 4. 下載到手機或電腦

想離線使用檔案，就先下載到裝置。

1. 網頁版在檔案上按滑鼠右鍵，選擇 Download to Device。App 中則開啟檔案的下載功能。
2. 開始下載後查看進度，直到完成。網頁版也可以查看瀏覽器的下載清單。
3. 開啟下載檔案的儲存位置，確認瀏覽器或 App 設定的下載資料夾。
4. 直接開啟檔案，確認下載結果可以正常使用。

App 內離線儲存與匯出到系統「照片」「檔案」可能是不同功能。若要在其他 App 中使用，請確認儲存位置或匯出選項。

![檔案選單：播放、下載與移動](https://appguideplus.com/assets/pikpak-file-menu.png)

網頁版無法下載整個資料夾。請逐一下載其中的檔案，或使用 PikPak 桌面版 App。

[官方資料夾下載說明](https://mypikpak.com/en-US/help-center/play_and_download/failure/web)

選單名稱可能因顯示語言與 App 版本而不同。

## 遇到問題先檢查這些

### App 裡看不到檔案

確認 App 與網頁版登入的是同一個帳號，重新整理檔案清單，並檢查儲存任務是否完成。

### 連結儲存失敗

確認連結有效、來源檔案仍可取得，帳號的儲存空間與傳輸配額還有剩餘。來源狀態也可能造成任務延遲或失敗。

### 雲端已經儲存，下載還是很慢

雲端儲存與下載到裝置是兩次不同的傳輸。請檢查網路、剩餘傳輸配額及帳號目前的使用條件。

### 找不到下載的檔案

從瀏覽器下載紀錄或 PikPak 下載清單開啟儲存位置。手機下載的檔案不一定自動出現在照片 App 中。
